💡 How to Connect Your Gmail (Step-by-Step)

Why normal Gmail passwords fail: Google disables direct password sign-in for security. You must use a 16-letter Google App Password.

  1. Open your Google Account: myaccount.google.com/security
  2. Make sure 2-Step Verification is turned ON.
  3. In the top search bar, type "App passwords" and click it.
  4. Create an App Password named "FinTrack".
  5. Copy the generated 16-character code (e.g., abcd efgh ijkl mnop) and paste it into the password fields below!
